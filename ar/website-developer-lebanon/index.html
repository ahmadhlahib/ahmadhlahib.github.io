تصميم وبرمجة مواقع إلكترونية في لبنان

أبني مواقع شركات وصفحات هبوط وتطبيقات ويب للشركات في بيروت وكل لبنان: سريعة على الهاتف، سهلة الظهور على Google، وبسيطة التحديث. النطاق والشيفرة والمحتوى ملكك أنت.

موقع يعمل لصالحك

معظم زبائنك سيرون موقعك على الهاتف، وغالبًا على إنترنت الخلوي. أبني صفحات تُحمَّل بسرعة، وتُقرأ جيدًا بالعربية والإنجليزية، وتقود الزائر إلى خطوة واضحة: الاتصال بك، أو مراسلتك على واتساب، أو الحجز.

أكتب برمجيات الويب منذ 2014، بدءًا بأنظمة ASP.NET لعملاء مثل GlobeMed، وأبني مواقعي بالطريقة نفسها، ومنها هذا الموقع.

صفحة لعبة بيروت سترايك

صفحة منتج للعبتي بالعربية والإنجليزية، مع الصور والميزات ومعلومات المتجر. ألقِ نظرة.

أنظمة موارد بشرية في Code Fish

أنظمة إدارة موارد بشرية على الويب بـ ASP.NET وC# لعملاء منهم GlobeMed وJubaili Co. وiEngineering.

الأدوات: HTML · CSS · JavaScript · ASP.NET · PHP · REST APIs · SQL · Firebase · GitHub Pages · Google Search Console

كيف نعمل معًا

  1. تعارفمكالمة قصيرة لفهم المشكلة والمستخدمين والأجهزة التي سيعمل عليها التطبيق.
  2. عرض مكتوبنطاق عمل مكتوب بالشاشات والمراحل، بسعر ثابت أو أجر يومي، كما تختار.
  3. تطويرنسخة تعمل كل أسبوع أو أسبوعين، تجرّبها على هاتفك أو حاسوبك وتوجّه العمل مبكرًا.
  4. تسليمنشر التطبيق، والشيفرة المصدرية كاملة، وملاحظات يستطيع فريقك المتابعة بها.

أسئلة يطرحها العملاء

كم تكلفة موقع إلكتروني في لبنان؟

موقع شركة بسيط أو صفحة هبوط بسعر ثابت صغير؛ أما تطبيق ويب بتسجيل دخول وبيانات فيُحدَّد نطاقه كأي مشروع برمجي. بعد مكالمة قصيرة تحصل على عرض مكتوب قبل البدء.

كم يستغرق بناء موقع؟

صفحة الهبوط تأخذ بضعة أيام، وموقع الشركة عادة من أسبوع إلى ثلاثة أسابيع، بحسب سرعة تجهيز المحتوى والصور.

هل سيظهر موقعي على Google؟

أجهّز كل ما يحتاجه Google: العناوين والوصف وخريطة الموقع والبيانات المنظّمة وSearch Console. الترتيب يأخذ أسابيع إلى أشهر، وملف Google Business مع التقييمات هو الأهم للبحث المحلي.

هل الموقع ملكي؟

نعم. النطاق يُسجَّل باسمك، وتحصل على الشيفرة كاملة وصلاحيات الاستضافة.

هل تستخدم الذكاء الاصطناعي في البرمجة؟

نعم. أعمل يوميًا مع وكلاء البرمجة مثل Claude Code، فيصل إليك العمل أسرع. وأراجع كل تعديل وأختبره وأفهمه قبل أن يصلك، ويمكنني أيضًا إضافة ميزات ذكاء اصطناعي إلى تطبيقك: التعرّف على الصور على الهاتف، والأوامر الصوتية، وتحويل النص إلى كلام بالعربية والإنجليزية.
