How I use AI coding agents to ship faster without breaking things

AI coding agents changed how I work in the last year. Used carelessly they write confident, broken code. Used with the right setup they let one developer deliver what used to take a small team. Here's the setup.

By Ahmad El Lahib · freelance developer in Baabda, Lebanon

1. Rules the agent reads before every task

Every project I work on has a short rules file that the agent loads at the start: the architecture, naming, what must never be logged, which tests to run, and what needs a human decision. On payment terminals that includes rules like "never log card data" and "every online transaction has a reversal path". The agent follows the same rules a new team member would, every time.

2. Tests are the guardrail, not an afterthought

An AI change is only done when the tests pass and the result works on the real device. For risky areas (amounts, dates, parsing, anything that talks to another system) the agent writes or updates a unit test with the change. For screens, I check the result on the phone or terminal itself. Nothing reaches a client because "the AI said it works".

3. Custom skills for repeated jobs

Jobs I do often become reusable skills: run the unit tests and summarise them, add a new item to an app's teaching content, analyse a device log. A skill is a short written procedure the agent follows, so the result is consistent and I don't explain the same thing twice.

4. Tools connected to the agent

Through MCP connections the agent can drive a browser to check a web page, read logs, or work with design files. For example, it checked this website at phone width and in right-to-left Arabic before I published it.

5. Real results

  • Test simulators in days, not weeks. My ECR Simulator (Windows and Mac) and Wireless ECR Simulator were built with an AI agent, with the protocol logic covered by tests.
  • Faster field debugging. Long device logs from a client site are summarised into a timeline, so the cause of a lost transaction or a dropped connection is found in minutes.
  • More time for the hard parts: talking to users, testing on hardware, and decisions a model shouldn't make.

FAQ

Only with the same checks as any other code: review, tests and testing on real devices. The agent speeds up writing; it doesn't replace verification.
